# POLESHIFT (폴시프트) — MAGNETIC PUZZLE
FLIP THE POLES. CHANGE THE GAME. / 극성을 뒤집어, 판을 바꿔라.

## 실행 방법
- `poleshift.html` 파일 하나를 브라우저(Chrome, Safari, Edge, Firefox)로 열면 됩니다. 서버, 외부 라이브러리, 이미지 파일, 사운드 파일이 없어도 실행됩니다.
- 재현 가능한 시드로 시작하려면 주소 뒤에 `?seed=123`을 붙이세요. 디버그 UI는 화면에 나타나지 않습니다.
- 로직 테스트: `node test_logic.js` / 브라우저 스모크 테스트: `python3 smoke.py` (Playwright와 Chrome 필요)

## 조작법
- **발사**: 점선으로 표시된 빈 칸을 터치한 뒤 🚀 발사를 누르면 현재 원이 그 칸에 놓입니다.
- **극성 전환**: 경기장에 놓인 원을 터치(점선 링으로 선택 표시)한 뒤 ⇅ 극성 전환을 누르면 N↔S가 바뀝니다.
- **취소**: 자기장 처리가 시작되기 전까지 선택을 해제합니다. 처리 중에는 모든 입력이 잠깁니다.
- 한 턴에는 행동 하나만 할 수 있습니다. 턴이 끝나면 다음 원이 공개됩니다.
- ⏸ 메뉴: 계속하기, 재시작, 규칙, 설정(효과음/진동/애니메이션 줄이기), 메인 메뉴
- 극성은 색 외에도 글자와 도형으로 구분합니다. N은 삼각형과 시안 테두리, S는 사각형과 마젠타 테두리입니다.

## 규칙 요약
- 궤도 3개 × 12칸 = 36칸. 인접 칸은 같은 궤도의 양옆 칸(원형으로 이어짐)과 안쪽·바깥쪽 궤도의 같은 각도 칸입니다.
- 자기장: 배치하거나 극성을 바꾼 원이 기준(고정)이 되고, 기준에서 2칸 이내에 있는 원이 반응합니다. 반대 극성이면 기준 쪽으로 끌려오고, 같은 극성이면 기준에서 멀어집니다. 펄스 한 번에 최대 1칸씩 움직이며, 한 턴에 펄스는 최대 3회입니다.
  - 처리 순서는 (기준까지의 거리, ID) 순입니다. 후보 칸은 (목표 거리, 같은 궤도 우선, 위치 번호) 순으로 고릅니다. 이동은 상태 복사본 위에서 계산하고 선점된 칸은 건너뜁니다. 갈 곳이 없으면 제자리에 남고 노란 ✕로 표시됩니다.
  - 이동이 없거나 같은 배치가 반복되면 그 즉시 안정 상태로 봅니다.
- 소거: 같은 색 원이 3개 이상 연결되면 사라집니다(극성은 무관). 남은 원은 코어 쪽 안쪽 궤도로 한 칸씩 끌려가는 재배치 펄스를 받습니다(최대 3회). 새 연결이 생기면 연쇄가 일어나며, 최대 10단계까지입니다.
- 게임 오버: 턴이 끝났을 때 빈 칸이 없으면 게임이 끝납니다. 꽉 찬 판에서는 극성을 바꿔도 원이 움직이지 않고 색도 바뀌지 않으므로 더 소거할 수 없습니다.

### 행성 테마 & 합체 규칙
- 4종 행성: 파랑 고리행성 / 빨강 크레이터 위성 / 노랑 줄무늬 가스행성 / 보라 얼음별(스테이지 4부터). 극성은 테두리로 구분 — **N = 실선, S = 점선** (+N/S 글자).
- 같은 종류 3개 이상 연결 → 가장 최근에 놓이거나 움직인 행성 자리에 **금색 나선 은하 1개로 합체**(극성 유지). 점수 = 그룹점수 + 은하 보너스 200.
- 은하 3개 이상 연결 → **초신성**: 은하 + 인접 행성 제거. 1000 + 은하×500 + 행성×150.
- 모든 점수 × 콤보 배율(1 + 0.5×(콤보−1)), 연쇄 최대 10단계.

## 갤러리 이미지 교체 방법
`poleshift.html` 안의 `POLESHIFT_GALLERY_IMAGES` 배열에서 `src`를 채우면 됩니다.
```js
{ rewardId: 'r1', src: 'images/reward1.jpg', alt: '설명', hue: 200 }
```
- HTML 파일 옆에 `images/` 폴더를 만들어 파일을 넣거나 URL을 지정하세요. src가 비어 있거나 불러오기에 실패하면 자체 제작 추상 카드가 자동으로 표시됩니다(`hue`로 카드 색 지정).
- 항목을 추가할 때는 `REWARDS`에 보상을, `POLESHIFT_GALLERY_IMAGES`에 같은 `rewardId`의 이미지를 함께 추가하세요.
- 현재는 실제 이미지가 들어 있지 않고 추상 플레이스홀더 카드만 있습니다.
- **콘텐츠 정책**: 명확한 성인(25세 이상) 여성의 세련된 패션 화보, 수영복·란제리 화보 수준의 비노골적 이미지만 사용하세요. 성적 행위, 성기 노출, 노골적 묘사는 금지합니다. 이미지는 갤러리 보상 화면에서만 보입니다. 이미지 생성 API 키를 클라이언트 코드에 넣지 마세요. 사용 권한(초상권, 저작권)이 있는 이미지만 쓰세요.

## 점수와 해금 조건 수정 방법
`POLESHIFT_CONFIG`에서 바꿉니다.
- `SCORE.PER_CIRCLE`(100), `BONUS_4`(100), `BONUS_5_BASE`(100), `BONUS_5_STEP`(200), `COMBO_STEP`(0.5)
  - 공식: 점수 = Σ(n×PER_CIRCLE + 보너스) × (1 + COMBO_STEP×(콤보−1))
- `MAX_PULSES`, `MAX_CHAIN`, `MIN_CLEAR`, `EASY_TURNS`
- `REWARDS[].cond`: `{type:'totalScore'|'maxCombo'|'gameScore', value:숫자}`
  - 기본값: r1 누적 1000점, r2 누적 3000점, r3 3콤보, r4 5콤보, r5 한 게임 10000점
- 화면에 표시되는 공식 문구는 `#formula` 요소와 규칙 화면의 RULES 텍스트에 있으니, 공식을 바꾸면 이 문구도 함께 고쳐 주세요.
- 누적 총점은 게임 오버 때 합산됩니다. 진행 중인 판의 점수는 해금 판정에만 미리 반영됩니다.
